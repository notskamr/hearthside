# Minecraft 26.3 GUI APIs (reference for Plans 5b–5d)

Researched 2026-10-11 from the decompiled 26.3 client and the Fabric API 0.162.0 jars. Paths are vanilla classes.
Some world, network and chat classes were not in the extract; their use here is inferred from client call sites.

## Screens
- `Screen(Component title)`. Override `init()` to add widgets with `addRenderableWidget` / `addRenderableOnly` /
  `addWidget`. Draw by overriding `extractRenderState(GuiGraphicsExtractor, mouseX, mouseY, partial)` (call super)
  and `extractBackground(...)`; Minecraft calls them through `extractRenderStateWithTooltipAndSubtitles`.
- Custom widgets: `AbstractWidget` with `extractWidgetRenderState(GuiGraphicsExtractor, int, int, float)`;
  `setAlpha`.
- Navigation: `FocusNavigationEvent.ArrowNavigation(ScreenDirection, previous)` / `TabNavigation(forward)`, resolved
  with `nextFocusPath`, applied with protected `changeFocus(ComponentPath)` (needs an accessor). **Vanilla has no
  gamepad support in menus** — Hearthside synthesises these events (or keeps its virtual cursor).
- Open: `minecraft.gui.setScreen(screen)`; current: `minecraft.gui.screen()`.
- **Blur only once per frame** (`GuiRenderState.blurBeforeThisStratum` throws on a second call): frosted panels use
  translucent fills, with at most one real blur behind a whole screen.

## Title screen
- `TitleScreen.init()` → private `createNormalMenuOptions(topPos = height/4 + 48, spacing 24)`: Singleplayer,
  Multiplayer, Realms (`"menu.online"`), then icon row, then Options/Quit.
- Fabric `ScreenEvents.AFTER_INIT` + `Screens.getWidgets(screen)` (mutable list; no `getButtons` in this version):
  insert "Co-op" under Singleplayer and shift the widgets below it down 24.

## Drawing (`GuiGraphicsExtractor`)
- `fill`, `fillGradient` (vertical), `outline`, `horizontalLine`, `verticalLine`.
- Sprites: `blitSprite(RenderPipelines.GUI_TEXTURED, id, x, y, w, h[, alpha | color])`; nine-slice via
  `assets/<ns>/textures/gui/sprites/<path>.png` + `.mcmeta`
  `{"gui":{"scaling":{"type":"nine_slice","width":W,"height":H,"border":N}}}`.
- Textures: `blit(pipeline, id, x, y, u, v, w, h, texW, texH[, color])`.
- Text: `text(font, Component|String, x, y, argb[, shadow])` — **alpha 0 draws nothing**, always pass ARGB;
  `centeredText`, `textWithWordWrap`.
- `enableScissor`/`disableScissor`; `pose()` is a 2D `Matrix3x2fStack` (push/translate/scale/rotate/pop);
  `nextStratum()` for layering; tint through the `int color` (`net.minecraft.util.ARGB`).
- HUD: `HudElementRegistry.attachElementAfter(VanillaHudElements.HOTBAR, id, (g, delta) -> ...)`.

## Fonts
- `assets/<ns>/font/<name>.json` `{"providers":[...]}`; `bitmap` (file under `textures/`, `height`, `ascent`,
  `chars`) or `ttf` (file under `font/`, `size`, `oversample`).
- Use: `Style.EMPTY.withFont(new FontDescription.Resource(Identifier.fromNamespaceAndPath(ns, name)))`.

## Player models and skins
- `GuiGraphicsExtractor.skin(Model.Simple, Identifier texture, scale, rotX, rotY, pivotY, x0, y0, x1, y1)`; reference
  widget `PlayerSkinWidget` (model `ModelLayers.PLAYER` / `PLAYER_SLIM`, scale `0.97*h/2.125`, pivot `-1.0625`).
- Skins: `PlayerInfo.getSkin()` → `SkinManager.createLookup(profile, secure)`; fallback `DefaultPlayerSkin.get`.
  Offline guests: register our own texture and supply a `PlayerSkin` (or mixin `PlayerInfo.getSkin`).
- Dynamic textures: `NativeImage.read(...)`; `textureManager.register(id, new DynamicTexture(id::toString, img))`
  on the render thread; `release(id)`.

## Worlds
- List: `levelSource.findLevelCandidates()` → `loadLevelSummaries(candidates)` (future of `List<LevelSummary>`).
- Open: `minecraft.createWorldOpenFlows().openWorld(id, onCancel)`.
- Create: `createFreshLevel(id, LevelSettings, WorldOptions, WorldPresets::createNormalWorldDimensions, parent)`.
- `CreateWorldScreen` tabs are private (Game/World/More); adding one needs a mixin on `init()`.

## Toasts
- `minecraft.gui.toastManager().addToast(Toast)`; `Toast`: `getWantedVisibility`, `update`,
  `extractRenderState(g, font, ms)`, optional `width/height/xPos/yPos/getToken`.

## Off-screen GUI
- No supported way: `GuiRenderer` renders into `mainRenderTarget` with the global window size and GUI scale.
  Practical route for compositor overlays: draw them in the host's own GUI pass inside its frame, or copy a
  rendered region. A true second GUI pass needs invasive mixins.

## Sound
- UI: `SimpleSoundInstance.forUI(sound, pitch[, volume])` → `soundManager.play(...)`.
- **One global output device** (`Options.soundDevice()`); per-player headsets need our own OpenAL context
  (`SoundEngine`/`Library` are single-device).
